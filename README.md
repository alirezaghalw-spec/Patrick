# Emo (Patrick)

ایمو: یک موجود شناور روی صفحه‌ی اندروید که راه می‌رود، به اعلان‌ها، شارژ، هدفون و اینترنت واکنش نشان می‌دهد، فارسی حرف می‌زند و دستور صوتی می‌فهمد.

## ساخت
- Android Studio یا `gradle assembleDebug` (Java 17، minSdk 26)
- GitHub Actions: workflow «Build APK» خروجی `emo-apk` را می‌سازد.

## اجازه‌ها
- نمایش روی برنامه‌های دیگر (ضروری)
- دسترسی به آمار استفاده (تشخیص بازی/ویدیو/دوربین، اختیاری)
- دسترسی به اعلان‌ها (فقط دسته‌ی اعلان خوانده می‌شود، نه متن آن؛ اختیاری)

## دستورهای صوتی
لمس طولانی روی ایمو: سلام، ساعت، برقص، بخواب، دوستت دارم، بخند، ساکت، بپر، حالت چطوره.
